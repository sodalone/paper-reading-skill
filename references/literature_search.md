# 外部文献检索规则

## 目录

1. 目标
2. 来源优先级
3. 查询策略
4. 核对与写入

## 1. 目标

外部检索只用于改变以下判断：

- 论文是否真的首创；
- 最接近的技术路线是什么；
- 是否存在直接竞争或反对证据；
- benchmark、方法或结论是否被后续工作修正；
- 复现所需的官方代码、项目页或评测协议。

不要为了凑相关论文数量扩展检索。

## 2. 来源优先级

1. 会议 / 期刊官方页面；
2. OpenReview；
3. arXiv 版本页；
4. 作者或项目官方页面；
5. 官方代码仓库；
6. 可核验机构仓库。

博客、聚合摘要、搜索结果片段和营销页面不能作为学术结论证据。

## 3. 查询策略

每次围绕一个可证伪问题检索：

- 论文标题或方法名 + `project` / `code` / `review`；
- 核心机制 + 最接近任务；
- 核心假设 + `limitation` / `counterexample` / `alternative`；
- benchmark + `comparison` / `evaluation`；
- 论文作者 + `response` / `revision`。

优先从原论文 references 找最近工作，再补论文发表之后的直接相关工作。

## 4. 核对与写入

写入报告前必须打开来源并核对：

- 标题、作者、年份和发表状态；
- 该工作实际提出的技术；
- 它与目标论文的具体一致或分歧点。

不要把“相关”自动写成“支持”，也不要把不同任务上的负结果写成直接反驳。

附录 C 只列正文实际引用的文献。每条最好包含可点击的官方或 arXiv 链接。

找不到直接证据时写：

> 当前未检索到对该具体机制的直接支持或反对证据；以下工作只构成竞争路线。
