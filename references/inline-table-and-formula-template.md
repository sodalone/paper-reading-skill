## 1. 正文公式选择

仅当满足至少一项时深入解释：

- 它定义论文核心机制；
- 它是训练目标中真正有新意的部分；
- 它决定理论结论的成立条件；
- 它直接解释关键实验或消融。

标准指标、坐标变换、常规 softmax、普通交叉熵和附录统计公式，除非改变结论，否则移入附录 B。移入附录不是删除：凡是支撑核心 Claim、复现或审计所必需的公式，都要在附录 B 保留定位和作用说明。

## 2. 公式解释模板

不要输出“公式理解卡”或 A/B/C 级标签。按自然叙事写：

```markdown
**为什么需要这条式子。** 用 1–2 句说明它填补哪一步。

**先看一个例子。** 给最小数值或场景例子，让读者先预测结果方向。

式 (n)：

$$ ... $$

- 只解释决定行为的关键符号；
- 说明它在机制、训练/推理、证明或分析中对应哪个步骤；
- 说明删掉或改变关键项会怎样；
- 说明证据和假设边界。
```

如果 toy example 比公式本身更复杂，省略 toy example，改用定性例子。

## 3. Markdown 数学兼容

- 行内数学使用 `$...$`。
- 块公式使用独立 `$$ ... $$`。
- 公式编号写在正文，例如“式 (7)”，不在公式块使用 `\tag{}`。
- 能单行就单行；确需多行才使用 `aligned`。
- 不在块公式中裸写以 `+`、`-`、`*` 开头的续行。
- 避免 `\mathbbm` 等依赖额外宏包的命令；指示函数可写为 `\mathbf{1}_{\{\cdot\}}`。
- 数学对象不用反引号；函数名、类名、命令和真实代码标识符使用反引号。

多行示例：

```markdown
$$
\begin{aligned}
\mathcal{L} ={}& \mathcal{L}_{\text{task}} \\
&+ \lambda \mathcal{L}_{\text{aux}}
\end{aligned}
$$
```

若目标渲染器不支持数学，公式后补一行纯文本伪公式；不要默认重复两种表达。

## 4. 证据载体与正文表格

表格不是跨论文的质量配额。先按论文类型选择证据载体：

- 理论论文：定义、假设、引理—定理依赖、证明关键步骤、反例与复杂度边界；
- 方法论文：机制对照、主结果、消融、泛化与代码语义；
- 系统论文：接口/协议、系统测试、吞吐/成本、失败案例与实现路径；
- 数据集 / benchmark：数据组成、划分、协议、覆盖、泄漏与公平性；
- 实证论文：对照、效应量、统计不确定性、稳健性与外推。
- 综述 / meta-analysis / 观点论文：检索或纳入标准、来源覆盖、综合方法、论证链、反方观点与遗漏。

只有表格能更清楚地表达重复字段或量化比较时才使用表格。理论论文无实验表、论文无图或原文无决定性公式都不是缺陷；不要为模板造内容。

### Claim—Evidence—Verdict

```markdown
| Claim | 原文位置 | 作者证据 | 支撑强度 | 最大缺口 | 本报告结论 |
|---|---|---|---|---|---|
| C1 | Sec. 4.1；Table 2 | 主指标提升 | 部分支撑 | 缺少直接消融 | 支持有效性，不支持因果归因 |
```

### 精简主结果表

```markdown
| 方法 | 核心设置 | 主指标 | 最强基线差值 | 结论 |
|---|---|---:|---:|---|
| Baseline |  |  |  |  |
| 本文方法 |  |  |  |  |
```

### 关键消融表

```markdown
| 变体 | 唯一变化 | 指标 | 相对完整模型 | 能验证什么 |
|---|---|---:|---:|---|
|  |  |  |  |  |
```

正文表格通常不超过 6 列。完整宽表放附录 A，并注明列来源和是否转录/计算。所有承载核心 Claim 的结论性表格必须在正文或附录 A 出现。若 Claim 由非表格证据支撑，则保存相应定理/证明依赖、反例、协议、系统测试、数据审计或代码定位；原文未提供某类证据时显式说明缺失及其判断影响。

## 5. 图片定位

优先依据：

1. arXiv 源码的 `\includegraphics`；
2. figure caption 与 label；
3. figure 所在 section；
4. 正文首次引用；
5. 文件名启发式。

插图格式：

```markdown
![Figure 2 方法全景](images/figure_02.png)
```

图后回答两件事：读者应该看哪里；这张图如何帮助理解方法或证据。不要只改写 caption。
