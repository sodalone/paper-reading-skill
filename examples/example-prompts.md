# 示例提示词

## 默认：理解优先

```text
使用 $paper-reading 阅读 https://arxiv.org/abs/2510.12796。
先让我在 20 分钟内建立方法直觉，再审查最关键的实验；完整公式、宽表和外部文献放在同一报告的附录。
```

## 审稿模式

```text
使用 $paper-reading 以 review 模式分析这篇论文。围绕 Claim—Evidence—Verdict 组织，不要重复同一质疑；重点检查实验对照、统计和结论外推。
```

## 复现模式与自定义目录

```text
使用 $paper-reading 以 reproduce 模式处理 2510.12796，输出到指定独立目录。重点核对论文与代码、训练/推理可见信息、超参数和最小复现路径。
```
